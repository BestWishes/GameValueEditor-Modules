日期：2026-10-06。配套主程序设计位于其 docs/STABILITY_OPERATIONS_STORAGE_AND_RECOVERY_DESIGN.md。

本次仅发布 WorldApart 1.3.3 和放置斩魔录 2.1.3，Last Epoch 保持 0.5.4，Host API 7/Schema 5 与最低宿主 0.4.4 不变。版本独立按十进制计数器加 0.0.1；主程序与模块均仅手动回退，各自保留最近 3 个正式包，标签保留。

模块视觉验证从 Git 的跟踪及未忽略源文件清单取得精确文件，再运行 rg，不递归扫描输出和其他目录。清单含未跟踪新源码，删除的文件跳过。
