# Deskrawl 1.0.2 发布记录

2026-10-15 用户授权提交并正式发布 Deskrawl 模块。主程序仍使用已发布的 0.5.4；宿主工作树中的异步诊断改动属于另一项工作。本次需要的共享背包页面读取委托一并提交，其他模块不重发。

## 版本与功能

已交付本地版本 1.0.0、1.0.1 登记在 `delivery-versions.json`，正式版使用下一编号 1.0.2，保证本地用户能更新。稳定模块 ID `game.deskrawl`，Host API 8，最低主程序 0.5.1，六个编辑器 ID 保持现有离线版身份。

- 人物属性：金币、当前经验、天赋点、独立巅峰点、基础主属性与三维属性；金币发现、物品发现、生命药水发现、材料发现、获得经验值按面板百分比换算。最终属性覆盖位于实际 getter，不再写入会被装备重算清除的加成字典。
- 装备生成：随机词条可取游戏合法区间最高值。
- 掉落规则：调整各类怪物掉落向量中的 NoDrop；独立提供 OfflineTradableDropMultiplier，因为稀有鱼和部分特殊物品路径不经过人物 MagicFind。
- 钓鱼：最终成功率，当前构建每次成功固定获得一个物品。
- 材料：中文名称和游戏自身数量/保存路径。
- 背包物品：仅显示当前已有的非材料可堆叠物品。

正式版仅启用清单登记的完整三文件构建，不根据方法存在或相似序言放行未知构建。兼容诊断不执行本地化主线程钩子；编辑动作仍由共享主线程门串行处理。

## 验证边界

本次发布复用前一轮精确构建实机证据：13 个人物字段、30 个中文材料、12 个已有可堆叠物品；装备词条、钓鱼成功率、十个 NoDrop 权重和特殊倍率完成写后回读与恢复。四个人物百分比同值覆盖通过延迟回读；这不等于完成每项结算和大样本掉落概率统计。此次发布验证不再修改游戏存档。

源码检查、全模块 Release 构建、实际模块页面加载、不可变 ZIP、带注释标签及远端资产/目录验证依照仓库发布工具执行。正式资产只含模块 DLL 和 module.json；完整离线 ZIP 保留为本地交付。
