# Deskrawl 1.0.4 正式发布

本版正式发布此前本地模块 1.0.3 已验证的小更新兼容修复与游戏声明信息读取。1.0.3 已作为离线包交付并登记版本；正式包从干净提交重新构建，使用下一个版本 1.0.4，不复用旧版本号或覆盖旧资产。

## 内容

- 未登记构建进入实际运行时验证，不再按旧文件哈希整包拒绝。
- 34 个入口按完整签名、完整规范化指令契约和唯一性定位，适应本次更新的混淆重命名；真实代码或结构不兼容时按能力安全拒绝。
- 提供游戏自报版本、产品名和构建 GUID，不以模块版本、引擎版本或 Steam 构建号代填。
- 两仓 AGENTS、扩展规范、模块模板、清单校验和发布回归统一强制小更新自动验证，不能通过关闭标志或仅补哈希交付。

Host API 8，最低宿主 0.5.1；模块和六个编辑器的稳定 ID 不变。宿主本次只提交规则和测试，不发布未改变的宿主二进制。

## 证据与边界

游戏 1.0.3 / Steam Build 25973417 的兼容性、声明信息、六页读取和受控业务写入证据见 [SMALL_UPDATE_1_0_3.md](SMALL_UPDATE_1_0_3.md)。保留该游戏构建未登记在精确哈希列表中的条件，验证真实的未知指纹路径；未知不等于直接放行。

发布前重新验证全模块构建、强制契约、语义与文件边界夹具、页面协调及真实正式 ZIP 的宿主加载。最终 DLL 的 ProductVersion 必须指向发布标签同一源码提交；公开资产核验成功后才更新目录，并保留历史不可变快照。

不承诺任意未来更新必然兼容，不把结构/读取验证冒充全部战斗掉落效果或重启持久化重新验收。原离线包保持不变，完整离线包不上传 GitHub。
