# 三内容模块完成方案（本地）

> 本文保留 0.0.2 的历史实施证据。其中“准备连接 / 自动重启”已在 0.0.3 删除，不能作为当前使用方法。当前方案与验收见 [直接接入实施记录](DIRECT_ATTACH_IMPLEMENTATION_LOCAL.md)，使用方式见 [本地说明](LOCAL_USE.md)。

## 范围与连接

仅制作“材料”“大转盘”“掉落”，不提交、不上传，不修改原游戏文件或 Steam 配置。

原游戏已运行且没有实时接口时，不强行注入或开启调试器。模块提供“准备连接”窗口：核验原启动器，等待用户正常保存退出，确认原启动器和主进程结束、端口空闲，再用原启动器自动附带仅本次有效的回环参数启动。用户无需编辑参数。准备窗口独立于旧模块页面的生命周期；关闭窗口、应用退出或五分钟超时取消等待。启动只执行一次，失败不重试，不强制退出游戏。重新进入存档并连接新实例后使用三页。

## 数据与界面

- 材料：保留已经实测的 29 项语义键、整数范围、原生保存与保存后核验。
- 大转盘：五类奖格总和 100%；额外奖励总和不超过 100%；类内相对权重，不自动抽奖。
- 掉落：分为总加成、战斗规则、矿区、奶牛关。每项单独启用，未启用保持游戏原规则。总加成使用百分点增减；金币词条实际控制金币收益加成，不伪称独立金币掉落概率。战斗概率是最终随机判定，保留原生保底/奖励数量。矿石品质合计 100%；奶牛关神话三项各自独立判定，奖池权重不得全零。
- 全部使用宿主主题、固定按钮顺序与统一间距。显示原值、设置及当前会话命中信息；恢复仅恢复当前内容模块。

## 正式入口验证

独立 runtime 字节码的验证不能代表正式 preview 合并代码。先使用正式游戏 Engine 的隔离副本追踪消费者，原 Engine、原材料、原存档、抽奖券不得被副本测试修改。固定精确 ASAR 指纹和调用位置；只有通过端点及中间概率、实际奖励/品质/金币结算测试的规则才启用。

## 协调与安全

读写重新核验进程启动身份、文件组合、接口监听者、存档身份、对象及版本回执。三页共用宿主写入队列和不确定操作日志；未确认写入不自动重试。页面输入仅映射固定白名单请求。概率重启恢复，不永久改装备词条，不替换全局随机函数，不触碰排行榜/服务器接口。

## 三轮设计检查

1. 范围：三个固定内容 ID；不添加人物、商城消费、额外掉率或批量自动行为。未勾选的设置保持原生值。
2. 安全：只正常启动；不强制结束、运行时强开调试口、改 ASAR、改 Steam 或恢复旧进度。准备窗口取消、超时、重复点击、端口占用和未知构建均停止。
3. 验证/交付：正式入口单独证明；模块测试覆盖三页输入、主题、生命周期、命名空间隔离；新本地包另起目录并检查 DLL/清单/压缩包条目与散列，保留之前的包。

## 实现与三轮回归（2026-10-08）

### 第一轮：契约、输入与隔离

完成固定三内容 ID、清单/DLL 0.0.2 同步；新增严格掉落白名单模型和 40 个输入，不允许脚本、未知项目、非有限数值、重复 JSON 字段或无效分组。全部 Node 回归 325 项通过；八个内嵌固定请求逐一核验，wheel / drops 独立管理且共享会话回执版本。取消、过期页面、缺少宿主桥接、无效输入和错误写入均不能绕过协调队列。

### 第二轮：运行入口与界面

用户正常保存退出后，使用相同模块启动类实际启动原安装，未修改 Steam、ASAR 或原存档。正式主进程、原 userData、回环接口、唯一窗口和隔离世界全部核验。DLL 只读客户端实际读取 29 项可写材料、16 个奖格和 40 个掉落输入，并渲染三个真实数据页面，另通过取消准备验证。

模块 C# 回归 180 项通过，包括三主题三页面、共享写入/恢复、真实宿主加载与源 DLL 不被锁定。发现并修正同步读取在 UI 线程调用时的异步上下文等待问题；增加 UI 同步通信回归。原游戏没有被测试助手关闭，停止的仅是卡住的自有测试进程。连接窗口支持取消、五分钟超时、进程/文件重验证、跨实例启动租约、重复 Loaded 防护和本次自动参数；保留接口已存在时的显式正常重启入口，供旧会话规则升级使用。

### 第三轮：实际消费者、包与文档

正式 `app/preview.js.jsc` 的隔离原生 Engine 新掉落 310 项通过，原有转盘与战斗规则 77 项通过。检查实际新装备数量/品质、金币结算、矿石品质、奶牛王各项及普通/不朽奖池所有物品，并覆盖中间概率和命名空间独立恢复。原 Engine 的序列化与保存内容保持一致、原抽奖券消耗为 0，不对原角色抽奖、战斗、保存或设置概率。

独立 runtime 旧回归 197 项、新掉落消费者 288 项仍通过，与正式合并入口证据分开记录。正式读取/副本验证回执：`artifacts/play-again-expedition/probability-control/read-64a31e80-c431-4149-a0b5-1d4a1efb69f6.json`。

本地组包使用已验证宿主 0.5.1 的冻结散列回执，验证 DLL/清单和模块 ZIP 仅两文件；调用宿主现有真实模块核验器加载所有预装模块、创建页面，并验证配套 EXE 启动。最终目录的 `local-package-receipt.json` 记录模块/清单/DLL 散列、页面核验报告和启动结果。所有候选均另起目录，不覆盖旧包，不触碰原安装/游戏库，也不提交、推送、打标签或上传。

最新用户说明和仓库入口已更新；研究文档保留历史阶段并在顶部注明现状。此次新掉落实机证据是正式 Engine 隔离副本加原游戏只读数据，不是原角色逐项战斗实玩。已确认先前材料/转盘实际重启闭环，不因页面模拟或读回相同数值而扩大声称范围。
