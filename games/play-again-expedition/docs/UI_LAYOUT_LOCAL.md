4. 回归：新增 `--ui-only` 模式，只用假客户端核验模型、页面与宿主加载。不运行会建立 TCP 监听的传输测试，也不扫描/接入原游戏。覆盖五种主题、取消/过期/错误/非法输入、正常应用和恢复，以及外层滚轮路由与边界。
5. 交付：清单、程序集和独立本地包均使用 0.0.4；以真实宿主验证三个页面的加载，再验证新目录应用启动。保留旧副本与历史验证记录。

## 实现依据

WPF 的 [PreviewMouseWheel](https://learn.microsoft.com/en-us/dotnet/api/system.windows.input.mouse.previewmousewheel) 是隧道事件，适合让外层滚动区域在内层表格之前处理滚轮；[WheelScrollLines](https://learn.microsoft.com/en-us/dotnet/api/system.windows.systemparameters.wheelscrolllines) 用于遵守系统滚轮设置。框架的 [嵌套滚动区域讨论](https://github.com/dotnet/wpf/issues/8353) 说明了内层控件吞掉滚轮的情形。
