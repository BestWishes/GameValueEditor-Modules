# Last Epoch 离线专属修改模块

当前模块版本：`0.5.7`；支持正常客户端中的离线角色和完全离线入口，不要求 `--offline`。历史本地记录中的未发布状态仅指当时的授权。

本版本使用 Host API 8。人物属性、装备、资源、异界进度和世界功能五个页面均由本模块程序集创建，并使用宿主提供的主题资源与间距；宿主只承载导航、视觉系统、生命周期和公共弹框/保存字段服务，页面布局不由 `Kind`/`Role` 模板决定。当前本地改动将游戏专属固定字段偏移改为当前元数据定位，保存链路和主线程业务调用保持原语义。

当前模块同时支持 Last Epoch 的普通离线和完全离线角色；按游戏当前游玩状态和角色的 `IsOffline` 判断，而不是启动命令行、默认联机选项、登录或聊天是否联网。尚未进入角色、联机游玩和状态读取失败分别提示。宿主先按游戏名称/别名识别，模块不再以历史 EXE、GameAssembly 与 metadata 哈希白名单拒绝整个游戏。小更新后按当前 IL2CPP 导出、类名、字段名和方法重新定位；资源、异界、摄像头、统计与脏标记等游戏字段不沿用旧固定偏移。旧构建指纹记录仅用于审计和隔离历史地址，不是当前运行入口门槛。

运行入口确认当前 Last Epoch 实例与 GameAssembly，模块连接只解析人物根及游玩状态，不预先要求所有可选页面和原生钩子通过。每个功能读取/修改时解析当前对象及字段，变化或未加载的属性标记不可用，不连带停用其它已能定位的功能。值类型嵌入字段依据当前元数据偏移减 IL2CPP 对象头，不沿用摄像头/库存位置的旧布局；通用数组/字符串 ABI 和序列化字节格式与游戏字段分开。原生钩子按当前方法定位，入口指令不支持时拒绝该项写入，不叠加未知补丁。0.5.7 在 Steam Build 25816319 的普通离线和完全离线角色实际读取了五页数据，碎片可逆修改及恢复后的重启持久化通过；新增验收与边界见 [两种离线入口方案](OFFLINE_SESSION_0_5_7.md)，历史逐项实战效果不扩大为此次重新测试。

## 编辑器

- 人物属性：修改剩余天赋点、剩余技能点、力量、敏捷、智力、协调、活力、移动速度、效果范围、提高冷却恢复速度、移动技能冷却恢复速度、经验倍率、总物品掉落率、金币倍率和药剂掉落率。装备掉落只提供一个“总物品掉落率”，作用于所有物品的最终生成概率；不再提供暗金、套装、金币堆频率或其他分类掉率。金币倍率只放大实际落地金币堆中的数量。通用冷却恢复已按游戏真正消费的 SP 70 `addedValue` 写入；移动技能冷却恢复已改为写入 `BaseStats.stats` 中可重建的闪避能力属性，而非会在施放时被覆盖的派生字段。两者均已通过原生冷却重建和实际连续施放验证，通用冷却还验证了切换地图。效果范围已改为写入最终区域技能计算所读取的 SP 116 `addedValue`，并由用户确认 300% 在实际技能中生效；该统计也会放大部分技能视觉特效，“收割”的镰刀虚影属于已知表现，按统一范围语义保留，不做技能特例。经验倍率已在最终经验结算入口验证 100% 会把角色经验从 10 放大到 20，不改动技能经验与阵营声望经验。药剂掉落按 SP 47 的 `addedValue` 重建最终概率并已观察到实战掉落增多；总物品掉落率直接作用于 `ItemDrop` 最终概率，并记录到了连续真实结算。运行期属性不会改动具体技能或专精节点，也不承诺写入角色存档。
- 装备编辑：只读取熔炉主槽当前放入的装备，并显示游戏中文名称；可修改锻造潜能、编织者意志、编织者之触和传奇潜能。更换装备后必须刷新，旧语义键不会误写新装备。
- 资源：对应游戏背包的“资源”页。页面顶部直接显示现有三类 `词缀碎片`、`符文与雕文`、`副本钥匙`，不提供“全部”；点击分类后，下方同一张表格立即列出该类全部资源，每行直接显示资源名称、数量、状态及修改/保存字段操作，不再使用左侧资源列表与右侧详情表的主从布局。名称优先取游戏当前语言的本地化表。已有运行期槽位会同步刷新数量；未持有的固定槽位也显示为 0，并可创建持久化记录。
- 异界进度：编辑最高腐化及已有时间线的腐化、稳定度、深度和奥罗比斯凝视；不会创建或解锁时间线。
- 世界功能：调整当前摄像头视野角度。该项属于当前场景状态，场景切换或重启后由游戏恢复。

普通背包中的装备和非堆叠物品不在本模块中修改。近战范围、地图迷雾和金币堆掉落频率已移出模块，不再保留入口或占位逻辑。场景生成阶段的刷怪密度同样不包装成稳定的怪物数量倍率。

所有操作都重新定位当前运行期对象并复读。人物统计写入使用一次性的 `CharacterStats.OnUpdateTick` 虚表入口，把 `AddStatModifier`、`UpdateStats`、属性专属重建和界面刷新放到游戏主线程执行；钩子进入目标人物后先自行恢复原虚表。其他路径只使用经过结构校验的直接字段、托管容器写入与游戏自身脏标记/保存循环。未知结构、在线模式或尚未加载的人物对象都会安全失败。

写入绑定当前离线角色；经验、掉落和金币原生钩子还会在游戏调用时检查当前离线状态及角色对象。离开角色、转联机或切换角色后旧倍率不继续作用，新角色需重新应用。不重写运行中的钩子正文；旧版未加角色门闩的钩子不升级、不叠加，若本次游戏已使用旧版倍率，需要正常退出再重开一次清除旧钩子（不是配置启动参数）。

更详细的对象链、语义键、兼容边界与失败经验见 [ANALYSIS.md](ANALYSIS.md)。
